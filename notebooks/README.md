# Colab

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/oguzbay-del/ocr/blob/main/notebooks/Unlimited_OCR_Colab.ipynb)

`Unlimited_OCR_Colab.ipynb` modeli ([Oguzbayrakdar/Unlimited-OCR](https://huggingface.co/Oguzbayrakdar/Unlimited-OCR)) ücretsiz Colab T4 GPU'sunda çalıştırır ve bir Gradio arayüzü açar.

1. Yukarıdaki butona tıklayın.
2. **Runtime → Change runtime type → T4 GPU**
3. **Runtime → Run all**, ardından son hücrede çıkan `https://….gradio.live` linkini açın.

Resim (PNG/JPG/WEBP/BMP) veya PDF yükleyebilirsiniz; PDF'ler sayfa sayfa işlenir ve sonuç Markdown olarak indirilebilir.
